# Lead Tracker — Frontend

React + TypeScript + Vite. See the [root README](../README.md) for
architecture, setup, and deployment instructions for the whole project.

Quick start:

```bash
npm install
cp .env.example .env.local   # set VITE_API_URL if the backend isn't on :8000
npm run dev
```

Other scripts: `npm run build`, `npm test`, `npm run lint`.
